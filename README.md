# Kill on Look (Fabric 1.21.4)

Клиентский мод: бьёт (или мгновенно убивает) сущность, на которую смотрит прицел,
или ближайшую сущность в радиусе атаки (режим «аура» с доворотом к цели).
Гуишка открывается на **Right Shift** (бинд перенастраивается).

## Что в гуишке
- Мод включён — главный переключатель
- Удары в секунду — ползунок от 1 до 10
- Враждебные мобы — зомби, скелеты, крипперы и т.д.
- Животные — коровы, свиньи, овцы, курицы, рыбы...
- Жители — жители и бродячие торговцы
- Игроки — другие игроки
- Мгновенно убивать (одиночная игра) — цель умирает сразу, без урона ударов
- Аура (бить без наведения) — бьёт ближайшую подходящую сущность в ванильном
  радиусе атаки (3.0 блока), перед ударом очень плавно доворачивая камеру к
  цели (30% оставшегося угла за тик); пока камера крутится, ударов нет, а удар
  идёт через 2 тика после доводки, чтобы сервер получил поворот до атаки
- Таргет-ESP (прямоугольник) — зелёная рамка вокруг текущей цели мода,
  видна сквозь стены, с именем цели над рамкой
- Открыть гуишку / Вкл-выкл мод — бинды: клик по кнопке, затем нажми клавишу
  (ESC — отмена). По умолчанию Right Shift и G. Гуишка закрывается по ESC

Настройки (включая бинды) сохраняются в `.minecraft/config/killonlook.json`.

## Важно
- «Мгновенно убивать» работает только в одиночной игре.
- Режим «аура» создан для тестирования собственного сервера с античитом GrimAC.
- На публичных серверах такое могут считать читом — использование на свой риск.

## Сборка из исходников
Нужен JDK 21 и Gradle 8.12. В корне проекта:
```
gradle build
```
Готовый мод появится в `build/libs/killonlook-1.0.0.jar`.

## Установка
1. Fabric Loader для Minecraft 1.21.4 (в Legacy Launcher ставится из списка версий)
2. Fabric API для 1.21.4 (https://modrinth.com/mod/fabric-api)
3. Оба jar — в папку `mods`
4. В игре: Right Shift — гуишка
