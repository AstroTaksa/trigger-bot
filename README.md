# Kill on Look (Fabric 1.21.4)

Клиентский мод: бьёт (или мгновенно убивает) сущность, на которую смотрит прицел.
Простая гуишка настроек открывается на **Right Shift**.

## Что в гуишке
- Мод включён — главный переключатель
- Враждебные мобы — зомби, скелеты, крипперы и т.д.
- Животные — коровы, свиньи, овцы, курицы, рыбы...
- Жители — жители и бродячие торговцы
- Игроки — другие игроки
- Мгновенно убивать (одиночная игра) — цель умирает сразу, без урона ударов

Настройки сохраняются в `.minecraft/config/killonlook.json` при каждом клике.

## Важно
- «Мгновенно убивать» работает только в одиночной игре (в мультиплеере мод просто
  бьёт цели обычным уроном).
- На публичных серверах такое могут считать читом — использование на свой риск,
  админы серверов могут забанить.

## Сборка из исходников
Нужен JDK 21. В корне проекта:
```
gradle build
```
Готовый мод появится в `build/libs/killonlook-1.0.0.jar`.

## Установка
1. Установи Fabric Loader для Minecraft 1.21.4 (https://fabricmc.net/use/installer/)
2. Скачай Fabric API для 1.21.4 (https://modrinth.com/mod/fabric-api)
3. Положи `killonlook-1.0.0.jar` и Fabric API в папку `.minecraft/mods`
4. Запусти игру с профилем fabric-loader
