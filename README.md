# Kill on Look (Fabric 1.21.4)

Клиентский мод в стиле чит-клиентов: клик-гуи с панелями, HUD-элементы,
аура со скрытной ротацией, аим-ассист, мгновенный тригер-бот.

## Клик-гуи (Right Shift, бинд перенастраивается)
Панели **Combat / Targets / Misc / Binds** с фиолетовыми шапками —
таскаются мышкой за шапку. Клик по строке — переключить.

- **Combat**: Аура (бить ближайшую цель со скрытной ротацией — камера не
  крутится, на F5 видно тело), Аим-ассист (плавно доворачивает камеру к цели,
  сам не бьёт), Тригер-бот (мгновенный удар, когда прицел коснулся видимой
  цели), Удары/сек (клик — сменить 1..10)
- **Targets**: Мобы / Животные / Жители / Игроки
- **Misc**: Авто-спринт, главный переключатель мода
- **Binds**: Гуишка (Right Shift), Тогл мода (G) — клик, затем нажми клавишу
  (ESC — отмена)

## HUD
- Водяной знак «Kill on Look» слева сверху
- Счётчик убийств за сессию (появляется после первого килла)
- Список включённых модулей справа (как ArrayList у чит-клиентов)

## Технические детали
- Скрытная ротация ауры: доворот уходит на сервер пакетами (миксин в
  `sendMovementPackets`), камера в первом лице не крутится, на F5 видно тело;
  удар — когда доворот «устоялся» 3 тика, пакет удара уходит ДО пакетов
  движения (как у ванили — иначе Grim флагает Post)
- Углы нормализованы (AimModulo360), прицел в центр хитбокса, доворот с
  потолком скорости 5°/тик (без «юлы»), цель «липкая»
- Тригер-бот: проверка видимости лучом (сквозь стены не бьёт)

Настройки (включая бинды) сохраняются в `.minecraft/config/killonlook.json`.

## Важно
- «Мгновенно убивать» работает только в одиночной игре.
- Режим «аура» создан для тестирования собственного сервера с античитом GrimAC.
- На публичных серверах такое могут считать читом — использование на свой риск.

## Сборка из исходников
Нужен JDK 21 и Gradle 8.12. В корне проекта:
```
gradle build
```
Готовый мод появится в `build/libs/killonlook-1.0.0.jar`.

## Установка
1. Fabric Loader для Minecraft 1.21.4 (в Legacy Launcher ставится из списка версий)
2. Fabric API для 1.21.4 (https://modrinth.com/mod/fabric-api)
3. Оба jar — в папку `mods`
4. В игре: Right Shift — гуишка
